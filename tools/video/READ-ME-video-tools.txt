VIDEO TOOLS — ECON 003
======================

One-time setup
--------------
1. Download ffmpeg for Windows:  https://www.gyan.dev/ffmpeg/builds/
   Take "release essentials" (a zip, no installer).
2. Unzip it, and copy ffmpeg.exe and ffprobe.exe from its bin\ folder
   into THIS folder, next to Cut.ps1 and Merge.ps1.
   (Or put them anywhere on your PATH if you prefer.)

That's it. Nothing else to install — PowerShell ships with Windows.


Using it
--------
Open this folder in File Explorer, type  powershell  in the address bar,
press Enter. Then:

  Trim everything after 17 minutes 11 seconds:
      .\Cut.ps1 video1943170784.mp4 -End 17:11

  Trim both ends:
      .\Cut.ps1 lecture.mp4 -Start 0:03 -End 17:11

  Join two takes into one file:
      .\Merge.ps1 -Out ECON003_Ch03_lecture.mp4 part1_cut.mp4 part2_cut.mp4

Each command prints the new length and file size when it finishes.
Typical run time is a couple of seconds — nothing is re-encoded, so the
video and audio are bit-for-bit the originals, just fewer of them.

If PowerShell refuses to run the scripts, once per machine:
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned


Finding the cut points
----------------------
That is the part worth handing to me. Send the file and I will find the
silences, the stumbles and the clean sentence boundaries, and give you the
exact timestamps to paste in. Reading a 400 MB file in is no problem; it is
only sending finished video back out that is capped.
